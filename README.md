# MountJoy Photographer

Premium multi-page photography website built with HTML, CSS and JavaScript for Visual Studio Code.

## Pages
- Home
- About
- Portfolio
- Services
- Packages
- Prints
- Blog
- FAQ
- Contact

## Open in VS Code
1. Open Visual Studio Code.
2. Click **File > Open Folder**.
3. Select the `mountjoyphotographer` folder.
4. Open `index.html` in your browser with Live Server or by double-clicking the file.

## Notes
- Social links are placeholder links and can be replaced later.
- Portfolio images currently use placeholder external images and can be swapped with your real galleries.
- The download guide is located in `assets/MountJoy-Photographer-Experience-Guide.pdf`.
- The site includes a `CNAME`, `robots.txt`, `sitemap.xml`, and `Dockerfile` for deployment.
